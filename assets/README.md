# Logistics Data Quality - Screenshot Assets

This directory contains visual assets for the Logistics Data Quality project.

## Screenshot Checklist

1. Dashboard Overview (`dashboard_overview.png`)
   - Main dashboard view showing rule-based and ML findings
   - Capture the primary dashboard view

2. Rule-Based Metrics (`rule_based_metrics.png`)
   - Validation metrics or dashboard view supporting rule-based results
   - Capture the metrics visualization section

3. ML Findings Detail (`ml_findings_detail.png`)
   - Detailed flagged manifest records or ML anomaly findings
   - Capture the detailed findings view

## How to Capture Screenshots

1. Run the dashboard:
   ```
   cd logistics-data-quality-copilot
   streamlit run src/dashboard/app.py
   ```

2. Navigate to http://localhost:8501

3. Capture the following views:
   - Main dashboard with findings
   - Rule-based metrics view
   - Detailed ML findings view
